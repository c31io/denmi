# 张量代数\n\n## 定义\n向量空间 $V$ 与 $W$ 的**张量积** $V\otimes W$ 配备一个双线性映射 $\otimes:V\times W\to V\otimes W$，其由下面的泛性质唯一确定。\n\n## 关键性质\n- **双线性**：$(v+v',w)=v\otimes w+v'\otimes w$，$(v,w+w')=v\otimes w+v\otimes w'$。\n- **基**：若 $\{e_i\}$、$\{f_j\}$ 分别是 $V$、$W$ 的基，则 $\{e_i\otimes f_j\}$ 是 $V\otimes W$ 的基。\n- **泛性质**：对任意双线性 $B:V\times W\to U$，存在唯一线性 $\tilde B:V\otimes W\to U$ 使得 $B(v,w)=\tilde B(v\otimes w)$。\n- **对称/反对称子空间**：$S^2V=(V\otimes V)/\langle v\otimes w-w\otimes v\rangle$，$\Lambda^2V=(V\otimes V)/\langle v\otimes w+w\otimes v\rangle$。\n- **度规张量**：在 $V$ 上的非退化对称双线性 $g_{ij}$ 给出同构 $V\cong V^*$。\n- **黎曼曲率**：$R^i_{\;jkl}=\partial_k\Gamma^i_{jl}-\partial_l\Gamma^i_{jk}+\Gamma^i_{km}\Gamma^m_{jl}-\Gamma^i_{lm}\Gamma^m_{jk}$。\n\n## 主定理（张量积的泛性质）\n对任意双线性映射 $\phi:V\times W\to U$，存在唯一线性映射 $\tilde\phi:V\otimes W\to U$ 使得 $\phi(v,w)=\tilde\phi(v\otimes w)$。该性质唯一（到同构）刻画了 $V\otimes W$。
